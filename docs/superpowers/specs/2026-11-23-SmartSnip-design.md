## 一、项目愿景与技术基座

### 1.1 项目定位

**SmartSnip** 是一款面向 Windows 10/11 的**轻量级常驻截图工具**，对标微信/QQ 截图的核心体验，提供**框选截图、贴图便签、文字识别（OCR）、二维码识别**四大能力。项目以「**低资源占用、零运行时依赖、随开随用**」为第一设计约束，作为系统级常驻工具，任何时刻不得对前台任务产生可感知的性能干扰。

### 1.2 技术基座

- **核心语言**：**Rust**（2021 Edition，stable 工具链），编译目标 `x86_64-pc-windows-msvc`，产物为**单文件原生 exe**，无任何运行时（.NET / JVM / WebView）依赖。
- **系统交互层**：
  - Win32 / WinRT 调用统一通过微软官方 **windows-rs** 绑定，不引入 cgo 式混合语言方案。
  - **OCR 引擎**：采用 Windows 系统内置 **Windows.Media.Ocr**（WinRT API）。程序不内置任何识别模型，零额外体积、零常驻模型内存；依赖系统已安装语言包，未安装目标语言时给出安装引导提示。
  - **屏幕捕获**：首选 **DXGI Desktop Duplication**（原生帧复制、支持高刷新率与 HDR 显示器），异常时自动降级 **GDI BitBlt**。
  - **二维码识别**：纯 Rust 实现的本地解码库（rqrr），**离线识别、无网络请求**。
  - **剪贴板**：PNG 位图（CF_DIB / PNG 格式双写，兼容 IM/办公软件）与文本写入。
- **图形渲染**：截图覆盖层与贴图窗口采用轻量原生窗口 + **CPU 软件光栅化**（softbuffer 系方案）或 GPU 单表面渲染，**坚决不引入 Electron / Tauri / WebView**。
- **目标环境**：Windows 10 1809+ / Windows 11，x64，per-monitor DPI（v2）感知。

### 1.3 版权与开发约束

- 最终生成的**全部源代码文件头部必须注入标准版权声明**，版权归属 **Winfxk（冰月）**，包含联系方式 **Email: admin@winfxk.cn / QQ: 2508543202** 及文件创建时间。
- 所有涉及**时间处理、时区换算、日期格式化**的逻辑，一律以**中国大陆（北京时间，UTC+8）**为准，不使用系统本地时区隐式换算。
- 遵循 Rust 官方 API 命名规范；模块间仅通过显式 `pub` 接口通信；禁止 `unsafe` 无审查扩散，所有 FFI 调用点集中收口。

## 二、部署模型与进程生命周期

### 2.1 安装与目录布局

采用**绿色自安装**模式，全部数据收敛于单一用户目录：

```
C:\Users\{UserName}\Winfxk\SmartSnip\
├── SmartSnip.exe          # 主程序本体（唯一可执行文件）
└── config\
    ├── config.toml        # 用户配置（快捷键、行为开关）
    └── logs\              # 运行日志（滚动清理）
```

- **首次运行即安装**：若 exe 不在目标目录，自动将自身复制至目标目录并以新路径重启，删除残留临时文件。
- **升级**：覆盖复制后重启进程，配置文件向前兼容（未知字段忽略、缺失字段回退默认值）。
- **卸载**：停止自启注册项 + 删除目录，无注册表残留（除自启项）。

### 2.2 单例守护与自启

- **单实例防多开**：通过命名互斥体（Named Mutex）实现全局唯一实例；二次启动时通过轻量 IPC 通道**唤醒既有实例**（如触发一次截图）后自行退出，避免出现两个热键监听者。
- **开机自启**：写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，指向固定安装路径；托盘菜单提供一键开关，修改即时生效并持久化。
- **异常恢复**：主循环捕获 panic 后记录日志并安全退出托盘资源，不产生僵尸窗口；提供崩溃日志定位指引。

### 2.3 资源生命周期策略（低占用核心）

- **常驻基线**：空闲状态仅持有 消息循环 + 托盘图标 + 热键句柄，目标常驻内存 **≤ 15MB**，CPU 占用 **0%**（无轮询，全部事件驱动）。
- **按需构造、即用即毁**：截图覆盖层、OCR 引擎、识别结果面板均为**惰性创建**；操作结束后立即销毁窗口与图像缓冲，归还内存。OCR 引擎完成一次识别任务后显式释放 WinRT 资源。
- **零轮询原则**：热键依赖系统消息派发；托盘、剪贴板监听全部基于窗口消息，禁止定时器轮询式设计。

## 三、UI/UX 架构

### 3.1 框选覆盖层（核心交互）

- **全屏遮罩窗口**：快捷键触发后，跨**所有物理显示器**创建无边框置顶遮罩层，整体压暗（半透明黑），光标变十字准星。
- **放大镜**：鼠标附近实时显示**像素级放大视图**（含坐标与颜色值），辅助精确框选。
- **智能吸附**（特色扩展）：检测鼠标下方的窗口/控件矩形边界，移动鼠标时自动吸附完整窗口框，点击确认；支持手动拖拽覆盖吸附。
- **尺寸提示**：框选过程中实时显示选区**宽 × 高（物理像素）**。
- **确认方式**：松开鼠标即确认（微信式）；`ESC` 取消；`Enter` 确认当前全屏选区。
- **多屏 DPI**：选区坐标全程使用**物理像素**，跨屏截图不做缩放模糊合成。

### 3.2 工具条（操作菜单）

- **触发位置**：选区确认后，工具条出现于选区右下角，越界时自动翻转到选区内侧或屏幕内侧。
- **功能项**（自左向右）：**标注画笔、矩形框、文字标注、截图（保存至剪贴板）、贴图、文字识别、二维码识别**。
- **标注模式**：进入标注模式后工具条切换为「当前工具 + 颜色（默认红/黄/蓝/黑四色）+ 撤销上一步 + 完成标注返回工具条」，支持**多次叠加标注**；标注结果同时作用于截图、贴图与识别输入。
- **视觉风格**：跟随系统**深色/浅色主题**自适应；控件全部原生绘制，无图片资源依赖。

### 3.3 贴图窗口（Pin 便签）

- **多实例并存**：每张贴图为独立无边框置顶窗口，**数量上限默认 20 张**（可配置），超出时提示并拒绝新贴，防失控。
- **窗口行为**：强制置顶（TOPMOST）、无边框无阴影、初始位置即截图时的屏幕位置（跨屏正确落位）、按物理像素 1:1 显示。
- **极简操控**：
  - 默认**仅悬停时**在贴图角落显示一个半透明小工具钮（非悬停完全隐入图片，不喧宾夺主）；
  - 工具钮展开：**关闭、复制到剪贴板、保存为文件、还原为可标注状态**；
  - **拖拽移动**：按住图片任意位置拖动；
  - **滚轮缩放**：以鼠标为中心 0.2× ~ 5× 缩放，双击还原 1×；
  - **透明度调节**：`Ctrl + 滚轮` 调整窗口整体透明度（40%~100%），便于透过贴图查看下方内容。
- **失焦淡化**（可选开关，默认开）：贴图失去焦点且鼠标离开 3 秒后，透明度自动降至 70%，交互时恢复。

### 3.4 系统托盘

- 托盘图标常驻；**左键单击**直接发起一次截图（最高频操作零学习成本）。
- **右键菜单**：立即截图 / 修改快捷键 / 设置（贴图上限、透明度、自启开关、标注默认色）/ 打开配置目录 / 检查更新（可选）/ 退出。
- **设置窗口**：惰性创建的单一原生窗口，含**快捷键录制控件**（按键捕获式，非下拉组合）。

## 四、核心功能模型

### 4.1 全局快捷键引擎

- **注册机制**：基于 `RegisterHotKey` 系统级注册；默认 **Ctrl + Alt + S**。
- **冲突处理**：注册失败即视为冲突，**弹出气泡提示**「快捷键已被 XXX 占用」并自动打开设置窗口引导修改；修改时先试注册新组合、成功后才替换持久化配置，保证任意时刻至少有一个可用热键（全部失败时回退默认值并告知）。
- **录制防呆**：设置页录制控件只接受含**至少一个修饰键**（Ctrl/Alt/Win/Shift ≥1）的合法组合；单键（如 F1~F12 单独使用需二次确认）予以明确警告，防止劫持常规输入。
- **扩展性**：配置模型天然支持多热键（如将来为贴图、OCR 设独立快捷键），首版仅启用主热键。

### 4.2 截图（Snip）

- 选区确认后按物理像素抓取原始帧 → 可选标注 → 写入剪贴板（PNG + DIB 双格式）→ 角落短暂浮现「已复制」轻提示后自动消失。
- **保存到文件**：工具条提供可选的「另存为 PNG」，默认目录为用户图片文件夹，文件名含时间戳（北京时间）。

### 4.3 贴图（Pin）

- 入口：工具条「贴图」；贴图来源为**当前选区含标注后的最终位图**。
- 生命周期与窗口行为见 3.3 节；贴图关闭即销毁窗口并释放位图内存，不做历史驻留。
- **退出保护**：应用退出时若存在贴图，弹出确认（防误触丢图）。

### 4.4 文字识别（OCR）

- **引擎**：Windows.Media.Ocr；识别前查询系统可用语言，**优先匹配中文（简体）与英文**。
- **结果面板**：识别完成后在选区旁弹出结果浮窗，正文按行呈现，提供 **「全部复制」** 与 **「手动选择」** 两种出口——手动选择模式将识别文本按行/段落渲染为可选中列表，便于只摘取局部内容。
- **语言引导**：若截图内文字对应语言未安装 OCR 语言包（识别结果为空或置信度极低），浮窗提示 **「如需识别其他语言，请在 设置 → 时间和语言 → 语言 中安装对应语言包」**。
- **性能策略**：单次识别限定输入尺寸（超长截图降采样）；识别全程在后台线程，浮窗先展示骨架再填充结果，不阻塞消息循环。

### 4.5 二维码识别（QR）

- **解码**：本地离线解码选区；未检出时明确提示「未发现二维码」而非静默失败。
- **内容分流**：
  - **纯文本 / 非跳转内容** → 直接写入剪贴板并浮窗展示全文；
  - **URL / App 协议跳转** → 弹出**确认对话框**，完整展示目标地址，用户确认后才调用系统默认方式打开；**绝不静默跳转**。
- **安全防呆**：识别出 `file://`、可执行协议（`ms-msdt:`、`search:` 等）等高危 scheme 时，确认框附加醒目风险提示。

### 4.6 智能扩展功能（首版内置，均为本地实现、零联网）

- **颜色拾取**：框选过程中放大镜面板即显像素颜色，支持点击**复制 HEX/RGB**（无需完成截图）。
- **智能窗口吸附截图**：见 3.1 节吸附能力，单击即截取整个窗口，替代手动对齐。
- **贴图标注直通**：已贴出的贴图可「还原为可标注状态」二次编辑（见 3.3 节）。
- **（预留）格式转换**：识别结果面板提供「去除多余空格/换行」一键清洗，面向 PDF 复制场景。

## 五、高级调度与容错引擎

### 5.1 资源感知调度

- **捕获方式自适应**：Desktop Duplication 初始化失败（被安全软件/远程会话干扰）时自动降级 GDI，并在日志中记录降级事件；下次捕获先尝试恢复高级通道。
- **OCR 限流**：短时间连续触发识别时复用引擎会话，识别间隔 < 500ms 的重复请求合并/排队，防止 UI 线程积压。
- **贴图内存预算**：所有存活贴图位图内存总量设上限（默认 512MB），逼近上限时提示「贴图过多」，避免超大规模截图拖垮系统。

### 5.2 防死锁与逃逸控制

- **全屏遮罩逃生**：遮罩窗口创建后即使渲染异常，`ESC`、`Ctrl+Alt+Del`、`Win` 键均保证可退出遮罩状态（遮罩注册为顶层但响应系统热键路径，不吞系统级按键）。
- **后台线程看护**：OCR / 解码等耗时任务设置硬超时（默认 10s），超时自动取消并提示，不允许出现永久转圈。
- **panic 隔离**：绘制、识别子模块的 panic 由 panic hook 捕获落盘日志，避免单功能故障导致进程整体崩溃。

### 5.3 错误处理模型

- **用户可见错误**三原则：**说人话**（不抛内部错误码）、**给出路**（每条错误附带可执行建议）、**不刷屏**（同类错误 60 秒内合并提示）。
- 错误分级：**可自愈**（自动降级+日志）→ **需提示**（气泡）→ **需交互**（对话框）。

## 六、持久化与日志审计

### 6.1 配置持久化

- **格式**：TOML（人类可读、可手改），写入采用**临时文件 + 原子替换**，防断电截断。
- **配置项模型**：快捷键组合、贴图上限、贴图默认透明度、失焦淡化开关、标注默认色、另存默认目录、自启开关、日志级别。
- **容错**：配置损坏时自动备份坏文件为 `config.toml.bak` 并以默认值重建，不阻断启动。

### 6.2 日志策略

- **落盘位置**：`config\logs\snip-YYYY-MM-DD.log`（北京时间命名）。
- **级别**：默认 `INFO`；设置页可切换 `DEBUG` 便于排查。
- **滚动清理**：保留最近 **7 天**，单日上限 **5MB**，超出截断；启动时惰性清理过期文件。
- **内容红线**：日志只记录事件与错误，**不落盘任何剪贴板内容、识别文本、截图数据**（隐私边界）。

## 七、交付与里程碑

| 阶段 | 交付内容 |
|---|---|
| **M1 骨架** | 进程生命周期（自安装/单例/自启/托盘）+ 全局热键 + 框选覆盖层（含放大镜）+ 截图入剪贴板 |
| **M2 核心** | 标注三件套（画笔/矩形/文字）+ 贴图多实例（缩放/透明度/工具钮） |
| **M3 智能** | WinRT OCR（结果面板 + 语言引导）+ 二维码识别（分流确认）+ 颜色拾取 |
| **M4 打磨** | 冲突引导、防死锁逃逸验证、日志/配置容错、多屏高 DPI 实测、安装器（可选 NSIS） |

**验收基线**：空闲内存 ≤ 15MB；热键响应 ≤ 100ms；框选到出图 ≤ 300ms；OCR 单屏选区 ≤ 2s；连续 24h 常驻内存增长 ≤ 2MB（无泄漏）。
